# VÍDEO 3: Git Remoto con GitHub y Colaboración (12-15 min)

## Para NotebookLM: Generar Vídeo de GitHub y Colaboración

---

Crea un vídeo sobre **Git remoto con GitHub y colaboración en equipo** para la unidad **UD03: Sistema de Control de Versiones** de la asignatura **Entornos de Desarrollo** del CFGS de **Desarrollo de Aplicaciones Web**, primer curso, curso 2026/2027, en el **IES Luis Vives** de Leganés. El profesor es **José Luis González Sánchez**.

El vídeo debe durar entre **12 y 15 minutos**, en **español de España (castellano)**, con **voz masculina**, tono **práctico y colaborativo**, como si le explicaras a un compañero cómo compartir código y trabajar en equipo. Usa una metáfora de **bodega en la nube**: GitHub es donde guardas tus cajas de código para que otros puedan verlas y ayudarte.

### Estructura:

**1. Portada:** Título EXACTO "Git Remoto con GitHub y Colaboración", subtítulo "UD03 · Entornos de Desarrollo · 1DAW · IES Luis Vives".

**2. Introducción (1 min):** "¿De qué sirve tener el mejor código del mundo si solo vive en tu ordenador?" GitHub es tu copia de seguridad y tu puerta al trabajo en equipo.

**3. Git vs GitHub (1,5 min):** Git es la herramienta, GitHub es la plataforma. origin y upstream. Clonar, crear repositorio con `gh repo create`.

**4. Push, Pull, Fetch (2 min):** git push -u origin main (tracking). git pull = fetch + merge. git fetch: revisar antes de fusionar. Diferencia fetch vs pull.

**5. SSH Keys (1,5 min):** Generar clave ed25519. ssh-agent. Añadir a GitHub. Verificar con `ssh -T git@github.com`. HTTPS vs SSH.

**6. Tags y Semantic Versioning (1 min):** git tag, git tag -a. MAJOR.MINOR.PATCH. git push --tags.

**7. Pull Requests (2 min):** Flujo: crear rama → commit → push → PR. gh pr create. Revisión: gh pr review. Merge: gh pr merge. Merge vs Squash vs Rebase.

**8. Fork y Colaboración (1,5 min):** gh repo fork. Flujo completo: fork → clone → branch → commit → push → PR. Sincronizar fork con upstream.

**9. Branch Protection y CODEOWNERS (1 min):** Reglas: requerir PR, tests pasados, revisiones. CODEOWNERS para revisores automáticos.

**10. Herramientas (1 min):** GitHub CLI (gh). GitKraken para visualizar. VS Code + GitLens para blame.

**11. Cierre (1 min):** "GitHub es donde demuestras tu trabajo a los empleadores." Consejo: crea un repositorio de portfolio. "Like y Suscripción para codificar un montón y nos vemos en el próximo deploy."
